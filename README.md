# Notes Management System 📚

## 📌 Description

A web application developed to manage academic information and organize student grades.

This project was created as a complete application, applying frontend and backend concepts to build a functional academic management system.

## 🚀 About the Project

The system allows users to manage academic information through a structured web application.

Features include:

- Student management
- Grade registration and organization
- Database integration
- Web interface for interacting with the system

## 🛠️ Technologies

### Backend
- Python
- Flask

### Database
- SQLite

### Frontend
- HTML
- CSS

### Tools
- Visual Studio Code
- Git and GitHub

## 📂 Project Structure

- `app.py` → Main application file
- `models.py` → Database models
- `templates/` → HTML templates
- `static/` → CSS, JavaScript and images
- `requirements.txt` → Project dependencies
